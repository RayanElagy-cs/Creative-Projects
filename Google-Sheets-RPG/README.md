# Google Sheets RPG

A fully functional RPG built entirely in Google Sheets without the use of Apps Script. It features an inventory system, enemies, boosts, tools, and resource-gathering nodes.

## Play the Game
https://docs.google.com/spreadsheets/d/1TEyUZPwMOjCqV6cvyJ-5BySdGGNLBIbwDoQoozh75JM/copy

## Features
- Inventory system
- Combat with enemies
- Boosts
- Tools
- Resource-gathering nodes
